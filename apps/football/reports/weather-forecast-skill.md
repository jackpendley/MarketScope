# Weather forecast skill (point-in-time)

Generated by `python -m marketscope_football.weather_report`. Forecasts: Open-Meteo Previous Runs API (CC-BY 4.0), averaged over the game window (kickoff hour + 3); lead N days = predicted at least N x 24 h before the hour. Observed: nflverse game-time temperature and wind (post-hoc). Outdoor venues only (retractable roofs excluded because the roof state is unknown). 546 games with forecasts, 2024-09-05 to 2026-10-22.

Temperature is forecast well a week out. Wind skill holds at 1 to 3 days and largely disappears by 7 days, so wind enters the totals model from short-lead forecasts only. The R3 study (does a wind forecast crossing 15 mph move the totals market, and when?) uses the 1 and 3-day leads.

Caveat: nflverse's observed wind is a single game-time reading, so part of the wind error is measurement noise, not forecast error.
