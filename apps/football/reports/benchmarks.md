# Benchmarks (MS-029)

_Generated by `marketscope_football.eval.run_benchmarks` on 2026-10-18. nflverse schedules via nflreadpy 0.1.5 (sha256 103b6c50e20b). Design pre-registered in `eval/design.py` before any result was computed._

## Setup

- **Walk-forward:** for each (season, week), every model predicts the week's games from earlier weeks only, then sees the results. Result columns are removed before `predict` is called.
- **Seasons:** warm-up from 1999; hyperparameters chosen on 2016–2022; headline table on 2023–2024 validation; 2025 untouched (the runner refuses it).
- **Games:** every completed game, regular season and playoffs. Outcome for win probability: home win 1, loss 0, tie 0.5.
- **Win probability from a margin:** Φ(margin / σ), σ = 11.90 fitted on 4,515 games from 1999–2015 closing lines. Elo uses its own logistic curve; the close uses the no-vig moneyline.
- **Intervals:** 95% bootstrap (5,000 resamples of games). Δ columns are paired differences (negative = better than the reference).

## Benchmarks

| Benchmark              | Definition                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| naive home field       | Recent league home margin (previous 3 seasons + current to date), 0 at neutral sites. Total: recent league mean                       |
| Elo (538)              | FiveThirtyEight NFL Elo as published: K 20, home field 65 Elo, revert ⅓ to 1505, margin-of-victory multiplier; spread = Elo diff / 25 |
| SRS (ridge)            | margin = r_home − r_away + HFA, weighted ridge refit weekly. Tuned: half-life 126 days, λ 4                                           |
| market-implied ratings | The same estimator fitted to past closing spreads (Inpredictable-style). Tuned: half-life 56 days, λ 0.5                              |
| nflverse close         | The closing spread, no-vig moneyline and total themselves                                                                             |
